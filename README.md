# DevTrack – Full Stack Task Management Platform

DevTrack is a full-stack project and task management platform designed to help users create projects, manage tasks, track progress, and use AI-powered task generation.

## Features

- User authentication
- Project creation and management
- Task creation and management
- Task priority management
- Task status tracking
- AI-powered task generation
- AI-generated task recommendations
- Dashboard for project and task overview
- Search and task management
- MongoDB database integration
- REST API backend
- Responsive frontend
- Production deployment using Vercel

## AI Task Generator

DevTrack includes an AI-powered task generation feature.

Users can enter a natural-language prompt such as:

> Create 3 tasks for completing my DevTrack project.

The AI generates suggested tasks with:

- Task title
- Project context
- Priority
- Status

Users can review the generated tasks and add the selected tasks to their task list.
